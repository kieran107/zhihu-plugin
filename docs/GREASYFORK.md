## 可复制的详细介绍

以下引用部分可用作平台描述；发布时保留原项目链接，不在描述中放引导用户绕过平台安装的备用下载链接。

> **在 iPhone 的 Safari 里，安静地读知乎。**
>
> 吉姆的知乎是一份面向 iPhone Safari「请求桌面网站」模式的 Tampermonkey 阅读脚本。基于知乎修改器二次开发，免费、非营利，与知乎官方无关联。
>
> **推荐列表**：淡点纹底板上的独立圆角卡片，分层阴影增强层次，顶部留白展示项目标题，满额后底部留白提示「已到底部了」，明暗主题自动适配；每轮最多 10 条过滤后的有效内容；完整标题、两行摘要、头像与作者、赞同数。关闭列表缩略图，读到底即结束；回到顶部使用 Safari 原生下拉刷新。
>
> **阅读回答**：一次展开一篇可收起的回答，其他回答淡化。正文优先，正文链接和划线评论按普通文字显示；小图点击优先看原图。底部是作者、评论、赞同、收起四个等宽胶囊，统一使用浅色深灰边、暗色白边；收起按钮随阅读悬浮，到底后归位。
>
> **阅读评论**：17px 正文配合清晰的作者与辅助文字，页内和回复弹窗排版一致；隐藏发评论和回复入口，保留排序、点赞及查看全部回复。页内与弹窗使用一致样式，并提供“收起评论”。点赞后红心与数字为柔和浅红色。
>
> **主题和预设**：跟随系统明暗主题，没有设置弹窗或调节图标。默认隐藏页头、侧栏、广告及 App 引导，并过滤视频、文章、想法、提问卡片、盐选、电子书及低于 100 赞的列表内容。预设还包含维护者的过滤词和本地“不感兴趣”记录，可在源码仓库的参数文件中查看及调整；本地过滤不会自动提交反馈，手动点击“不感兴趣”会提交知乎反馈。
>
> **使用前**：启用 Safari 的 Tampermonkey，并允许访问知乎；为知乎开启「请求桌面网站」。只启用本版，停用原版和其他同类脚本。推荐上限只作用于首页推荐，其他列表不受该数量限制。若过滤后可用内容不足，可能少于 10 条。
>
> **来源与致谢**：直接基于 lyb233 的 [知乎修改器](https://greasyfork.org/zh-CN/scripts/423404) 网页端 5.21.4（[GitHub](https://github.com/liuyubing233/zhihu-custom)），参考 liuyubing 的 [知乎修改器移动版](https://greasyfork.org/zh-CN/scripts/488508) 2.9.4（[GitHub](https://github.com/liuyubing233/zhihu-custom-mobile)）。两者脚本标注 MIT；本项目保留署名与许可，手机阅读布局和维护流程在本仓库独立维护。
>
> **数据**：设置和本地记录保存在浏览器内；内容、头像、点赞及反馈使用知乎本身的页面和接口。本项目不设置独立数据收集服务，不加入广告或付费解锁。
>
> **兼容性**：面向 iPhone Safari + Tampermonkey，主要适配 iPhone 16 Pro。桌面浏览器手机模拟检查不等于 iPhone 实机测试；知乎改版可能影响部分功能。问题可在本页反馈或提交 [GitHub Issue](https://github.com/kieran107/zhihu-plugin/issues)。
>
> **许可**：MIT，非营利是项目运营声明，不额外限制 MIT 授予的使用权。源码、参数、更新日志和许可见 [项目主页](https://github.com/kieran107/zhihu-plugin)。

## 上架步骤

1. 使用维护者账号新建脚本，上传当前完整的 `吉姆的知乎-iPhone.user.js`；不要上传 `.meta.js` 作为脚本，不要同时上传两份第三方原文件。
2. 保留名称、namespace、原作者署名和内附 MIT 许可；填写上面的介绍。说明 iPhone 阅读布局与原作的实质差异。
3. 按平台页面提示完成发布；取得真实脚本 ID 和链接后，再把它加入 README。不要提前编造安装地址。
4. 如需从 GitHub 同步，使用平台届时提供的脚本同步配置，指定本仓库 `main` 的完整 `.user.js` Raw 地址。实际验证一次同步后再启用长期流程；目前发布命令只推 GitHub。
5. 首发后检查平台分发源码、`@version`、生成的更新地址，验证安装与下次更新。继续保留 GitHub 原有路径，以免影响老用户。

## 两个渠道的区别

| 安装来源 | 后续检查位置 |
| --- | --- |
| 当前 GitHub Raw 安装包 | 本仓库固定 `.meta.js`／`.user.js` 地址 |
| 将来的 Greasy Fork 安装包 | Greasy Fork 生成的更新地址 |

Greasy Fork 会改写 `@updateURL`／`@downloadURL`，因此“GitHub 已推送”不等于“Greasy Fork 已同步”。同名、同 namespace 的脚本也不应作为两个副本同时运行。现有用户可以继续使用 GitHub 渠道，无需为了上架而重新安装。版本编号重置是另一回事：旧 6.0.0／5.x 用户仍须手动覆盖安装当前 1.x 一次。
