# 吉姆的知乎 · iPhone Safari

**在 iPhone 的 Safari 里，安静地读知乎。**

面向「请求桌面网站」模式的 Tampermonkey 阅读脚本。把知乎桌面网页整理成适合手机的单栏卡片列表：先看标题与摘要，点开一篇认真读，读完收起。

本项目基于 **知乎修改器** 二次开发，针对 iPhone 的阅读流程持续调整。免费、非营利，代码以 MIT 许可证开放；与知乎官方无关联。

**[安装／更新脚本][install]** · [参数说明](iPhone知乎-参数.md) · [更新日志](CHANGELOG.md) · [反馈问题][issues]

## 阅读体验

| 场景 | 本版的处理 |
| --- | --- |
| 浏览推荐 | 每轮最多 **10 条有效内容**，读到底就结束；回到顶部使用 Safari 原生下拉刷新 |
| 列表首尾 | 顶部留白展示项目标题与「↑ 上拉刷新」提示；本轮满额后，底部留白显示「已到底部了」 |
| 收起的列表 | 淡点纹底板上的独立圆角卡片，分层阴影增强悬浮感；完整标题、最多两行摘要、头像与作者、无千位逗号的赞同人数；不显示列表缩略图和评论数 |
| 展开回答 | 标题下直接阅读正文；一次展开一篇可收起的回答，其他回答淡化，切换时自动收起上一篇 |
| 正文排版 | 较大字号、适量留白；正文链接和划线评论转为普通文字，减少误触 |
| 图片 | 正文小图限高，点击优先查看原图，保留浏览器双指缩放 |
| 回答操作 | 底部四个等宽胶囊：作者、评论、赞同、收起，统一深灰／白色边框；收起按钮悬浮并在第四格归位 |
| 评论阅读 | 正文 17px、作者与辅助文字分级放大，页内和回复弹窗一致；隐藏发评论、回复输入和回复入口；保留排序、点赞、展开全部回复与独立的“收起评论” |
| 明暗主题 | 随设备自动切换；评论已赞为柔和玫瑰红，无主题开关或设置弹窗 |

10 条限制仅作用于**首页推荐**，按过滤后的有效内容计数；若知乎返回的合格内容不足，可能少于 10 条。关注、热榜和问题详情不套用该上限。底部没有刷新手势或“点击刷新”按钮。

## 安装

1. 在 iPhone Safari 安装并启用 [Tampermonkey](https://www.tampermonkey.net/)，允许它访问知乎网站。扩展本身是否收费，以应用商店为准；本脚本免费。
2. 在 Safari 中为 `www.zhihu.com` 开启并保持 **「请求桌面网站」**。
3. 打开 **[安装／更新脚本][install]**，在 Tampermonkey 中确认安装。若只显示源码，可使用扩展的「从 URL 安装」功能。GitHub 仓库首页不是安装地址。
4. 停用原版知乎修改器、旧移动版和其他同类脚本，只保留本版；刷新知乎。
5. 在 Tampermonkey 中启用脚本更新检查和自动安装更新。具体选项以当前 iPhone 版本界面为准。

面向 iPhone Safari + Tampermonkey 维护，主要适配设备为 iPhone 16 Pro。日常回归也使用已登录 Chrome 的手机尺寸模拟；这不等同于 iPhone 实机验证。Android、其他脚本管理器及桌面端不在本版的重点验证范围。

### 已经安装过？

**从 `6.0.0` 或旧 `5.21.4-iphone.N` 切换到 `1.x`，需通过上方安装链接手动覆盖安装一次。** 这是版本编号重置，管理器不会把较小的版本当成自动更新。确认替换同名脚本即可，不必先删除；名称、namespace、存储键与文件路径保持稳定。已经使用 `1.x` 的用户，后续继续由 Tampermonkey 自动更新。

Tampermonkey 按自身调度检查并安装更新，受网络、扩展运行状态及缓存影响，**不是即时推送**。更新后重新加载知乎才会使用新代码；急需新版本时，可在扩展里手动检查更新。仓库无法远程修改手机扩展设置，也无法保证锁屏后台更新。

## 默认行为与参数

本版没有网页设置面板，预设集中在 [iPhone知乎-参数.md](iPhone知乎-参数.md) 的 JSON 中，发布时写入脚本。

默认偏向文字阅读：隐藏页头和侧栏、广告及 App 引导；过滤视频、文章、想法、提问卡片、盐选、电子书及低于 100 赞的列表内容。页头里的导航和搜索也会隐藏。问题详情不按这个赞同门槛过滤。

当前预设继承维护者的阅读偏好，包含标题过滤词和本地“不感兴趣”记录，具体条目可在参数文件审阅。它们只用于本地过滤，不会自动向知乎补发反馈。更换自己的偏好时，请先检查这些列表及 `lessVoteNumber`。手动点“不感兴趣”仍会向知乎提交正常反馈。

- 修改参数文件后运行发布命令；手机不会直接读取 Markdown。
- 每次加载优先使用代码预设；本地新增的屏蔽记录会合并保留。
- 从 JSON 删除一项不会自动抹掉浏览器内已经保存的记录。
- 自行修改已安装脚本可能影响管理器后续更新；建议统一在自己的源码副本中维护。

## 数据与权限

脚本在知乎网页内工作，读取页面及知乎接口返回的数据，调整展示与推荐过滤。设置和本地记录通过 Tampermonkey 存储及浏览器 `localStorage` 保存。

请求仍由浏览器发送给知乎：包括推荐、评论、必要时补取作者头像，以及你主动触发的点赞和“不感兴趣”。本项目不设置独立数据收集服务，不加入广告、付费解锁或推广返利；GitHub 负责源码与更新文件分发。`unsafeWindow` 用于衔接页面环境，`GM.getValue/setValue/deleteValue` 用于存储；没有远程 `@require` 依赖。

## 常见问题

**装了没有效果？** 先确认请求的是桌面网站、扩展有知乎权限、脚本已启用且只启用一个版本，再重新加载页面。

**怎么只有 10 条、怎么没有写评论入口？** 这是当前设计：限制连续刷推荐，评论以阅读为主。参数中可调整 `mobile.feedBatchSize` 或 `mobile.readOnlyComments`。

**为什么正文链接点不开？** 展开回答里的链接和划线评论按普通正文处理，避免阅读时误触；并非网页加载故障。

**知乎改版后布局异常？** 脚本依赖知乎页面结构和接口，网站改版可能造成局部失效。可先停用脚本恢复原页面，再向 [Issues][issues] 提供脚本版本、iOS／Safari 版本、页面链接、复现步骤与脱敏截图。请勿提交 Cookie、令牌或私信内容。

## 开发与版本

当前采用简洁的 **`1.0、1.1、1.2……1.10`** 编号，与上游基线版本分开记录。每次脚本更新将点后的整数加一；只改文档不升级脚本。旧的 `6.0.0` 和 `5.21.4-iphone.N` 保留为历史记录，不再用于新版本。

```sh
node 发布更新.cjs --check  # 只检查，不修改、不上传
node 发布更新.cjs          # 同步参数、检查、提交、推送、核对 Raw
```

需要 Node.js 18+、Git 及仓库推送权限；macOS 也可使用 `一键发布.command`。发布逻辑没有 npm 依赖。详见 [开发与发布](docs/DEVELOPMENT.md)。
